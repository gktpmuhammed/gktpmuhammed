### Prostate Cancer Aggressiveness Prediction

End-to-end PET/MRI deep learning pipeline for prostate cancer aggressiveness prediction:

- 2D and 3D model variants,
- prostate and tumor-region preprocessing,
- segmentation-aware classification,
- hyperparameter tuning and k-fold cross-validation,
- experiment tracking with Weights & Biases.

Repository: [Prostate-Aggressiveness-Prediction](https://github.com/gktpmuhammed/Prostate-Aggressiveness-Prediction)

### LLM-Based Radiology Report Decomposition

Structured organ-wise decomposition of CT reports using:

- vLLM inference,
- MedGemma,
- Pydantic schemas,
- deterministic structured extraction,
- robust JSON parsing and batch processing.

Repository: [report_decomposition](https://github.com/gktpmuhammed/report_decomposition)
